# hifz_vision releases

Public download point for the hifz_vision Android app. No source code lives here.

- `apk/hifz_vision-latest.apk` — always the newest build. This is the link testers use for
  their first install.
- `apk/hifz_vision-<version>-<code>.apk` — every published build, kept for reference.
- `update.json` — read by the installed app to discover newer versions.

Installation instructions for testers are sent with the download link.
